# 🎉 Happy Birthday — праздники нашего чата

Telegram-бот и Mini App для дней рождения в группах. Без спама: в группе размещается одна постоянная панель, а в дни рождения — персональные поздравления с необязательным закреплением. Новогодние желания и адреса ПВЗ Wildberries/Ozon появятся на следующем этапе; «Тайного Санты» не будет.

## Этап 1
- Mini App для мобильного Telegram: сохранение дня/месяца, необязательного года, приватности.
- Календарь и ближайшие дни рождения.
- Автоматическое поздравление в группе по её часовому поясу, с персональным упоминанием.
- Закрепление поздравления и снятие закрепления на следующий день, только у сообщения бота.
- Настройки для администраторов (время, часовой пояс, закрепление).
- Проверка подлинности Telegram Mini App initData и членства в группе.

## Запуск

1. Создайте бота в @BotFather и скопируйте токен.
2. Подготовьте HTTPS-адрес Mini App (домен и reverse proxy на порт 8000).
3. В @BotFather настройте **Main Mini App** с HTTPS-адресом `https://ваш-домен/`. Без этого ссылки из групп `https://t.me/имябота?startapp=c-100...` не будут открывать приложение.
4. Скопируйте `.env.example` в `.env`, заполните `BOT_TOKEN` и `BASE_URL`.
5. Запустите: `docker compose up -d --build` (или `pip install -r requirements.txt && uvicorn app.main:app --host 0.0.0.0 --port 8000`).
6. Добавьте бота в группу администратором, разрешите **закреплять сообщения**. В группе администратор пишет `/holidays` — появляется единая панель с кнопками Mini App.
7. Для проверки: `GET /health`; откройте приложение **в Telegram**, не обычным браузером.

Хранение: файл SQLite в `./data` (в Docker volume). Не запускайте одновременно несколько копий приложения с одним токеном и БД. Регулярно копируйте `data/`.

## Устройство

`app/main.py` — FastAPI + Telegram polling + планировщик в одном процессе; `app/bot.py` — команды и кнопки; `app/api.py` — защищённый API Mini App; `app/db.py` — хранилище; `app/scheduler.py` — отправка и закрепление; `app/static/` — адаптивный интерфейс.

## Приватность

Год рождения необязателен. Публичное поздравление и отображение в календаре настраиваются участником. API проверяет Telegram initData, его срок и принадлежность к конкретной группе. Ссылочный `startapp` **не является авторизацией**. Дату можно удалить в профиле. Новогодние адреса ПВЗ будут опциональными и ограниченными по доступу.

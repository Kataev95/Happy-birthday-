# 🎉 Happy Birthday — праздники нашего чата

Telegram-бот и Mini App для дней рождения в группах. Без спама: в группе размещается одна постоянная панель, а в дни рождения — персональные поздравления с необязательным закреплением. Новогодние желания и адреса ПВЗ Wildberries/Ozon появятся на следующем этапе; «Тайного Санты» не будет.

## Этап 1
- Mini App для мобильного Telegram: сохранение дня/месяца, необязательного года, приватности.
- Календарь и ближайшие дни рождения.
- Автоматическое поздравление в группе по её часовому поясу, с персональным упоминанием.
- Закрепление поздравления и снятие закрепления на следующий день, только у сообщения бота.
- Настройки для администраторов (время, часовой пояс, закрепление).
- Проверка подлинности Telegram Mini App initData и членства в группе.

## Запуск

1. Создайте бота в @BotFather и скопируйте токен.
2. Подготовьте HTTPS-адрес Mini App (домен и reverse proxy на порт 3000).
3. В @BotFather настройте **Main Mini App** с HTTPS-адресом `https://ваш-домен/`. Без этого ссылки из групп `https://t.me/имябота?startapp=c-100...` не будут открывать приложение.
4. Скопируйте `.env.example` в `.env`, заполните `BOT_TOKEN` и `BASE_URL`.
5. Запустите: `docker compose up -d --build` (или `pip install -r requirements.txt && PORT=3000 python -m app.main`).
6. Добавьте бота в группу администратором, разрешите **закреплять сообщения**. В группе администратор пишет `/holidays` — появляется единая панель с кнопками Mini App.
7. Для проверки: `GET /health`; откройте приложение **в Telegram**, не обычным браузером.

Хранение: файл SQLite в `./data` (в Docker volume). Не запускайте одновременно несколько копий приложения с одним токеном и БД. Регулярно копируйте `data/`.

## Устройство

`app/main.py` — FastAPI + Telegram polling + планировщик в одном процессе; `app/bot.py` — команды и кнопки; `app/api.py` — защищённый API Mini App; `app/db.py` — хранилище; `app/scheduler.py` — отправка и закрепление; `app/static/` — адаптивный интерфейс.

## Приватность

Год рождения необязателен. Публичное поздравление и отображение в календаре настраиваются участником. API проверяет Telegram initData, его срок и принадлежность к конкретной группе. Ссылочный `startapp` **не является авторизацией**. Дату можно удалить в профиле. Новогодние адреса ПВЗ будут опциональными и ограниченными по доступу.

## Следующий этап

Красивые открытки и новогодние списки желаний: фото/ссылка/цена, **необязательные** пункты выдачи Wildberries и Ozon, скрытые от общего чата, приватное бронирование подарков. Без автоматических сообщений о желаниях в группу. Без «Тайного Санты».

## Развёртывание на BotHost (Bothost)

Проект адаптирован под BotHost: сервис использует стандартную точку входа `python -m app.main`, слушает `0.0.0.0`, читает порт из `PORT` (обычно `3000`) и автоматически строит HTTPS-адрес Mini App из переменной `DOMAIN`. `BASE_URL` можно передать вручную, тогда он имеет приоритет.

1. В BotHost выберите GitHub-репозиторий `Kataev95/Happy-birthday-`, ветку `main`. После обновлений GitHub **пересоберите и перезапустите бота**.
2. Во вкладке **Домен** установите `bot-1794821354-7486-pablo.bothost.tech`, порт **3000**; сохраните. Если используется другой адрес, укажите его.
3. В переменных окружения проверьте `BOT_TOKEN` (хранить только в панели хостинга). По желанию явно добавьте `BASE_URL=https://bot-1794821354-7486-pablo.bothost.tech`, если `DOMAIN` не передаётся.
4. Для проверки откройте `https://bot-1794821354-7486-pablo.bothost.tech/health`. Должен вернуться JSON `{"ok":true,"service":"happy-birthday"}`. Главная `/` отдаёт Mini App.
5. В Telegram BotFather → Main App вставьте **полный URL** `https://bot-1794821354-7486-pablo.bothost.tech/`. Без `https://` BotFather выдаёт «URL is invalid».
6. В BotHost проверяйте **логи работы**, не только успешную сборку. При `404` без запросов к Python проверьте, что прокси домена подключён; BotHost может потребовать обновить маршрут после деплоя.

База данных: `/app/data/holidays.sqlite3` при рабочей папке `/app`. Храните `/app/data` в постоянном томе BotHost; не записывайте БД в корень временного контейнера.

**Важно:** URL в BotFather заработает только после исправного запуска HTTP-сервера по HTTPS. 404 от прокси не всегда означает проблему Mini App.
